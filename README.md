# KK’s Learning Center IV — Website

Five-page responsive Vite-ready static website. `npm install`, `npm run dev`, `npm run build`. Output directory: `dist`.

Source: https://docs.google.com/spreadsheets/d/1YeTideVr3dw1LvuaeGFmufEsqwE5VB_k1NRu9PhwVMY/edit#gid=161994001 (row 40); Oklahoma Human Services record: https://childcarefind.okdhs.org/providers/K830058227

Pages: Home, Programs, Our Center, FAQs, Contact.

Brand: user-supplied logo with butterflies, lavender/pink accents and dark burgundy typography. Design uses mauve, cream, lavender, sage, soft peach. The logo reads 'West Siloam Springs' while the official listing gives a Colcord mailing address.

Facebook link is retained only in the internal audit until its ownership is independently confirmed.

The Facebook URL comes from the spreadsheet but could not be independently confirmed as belonging to this provider, so it has been excluded from the published website; see audit. No Instagram URL was provided, so none was added.

No licensed capacity appears in any publicly served page. Images from Pexels are illustrative, not the actual childcare center.
